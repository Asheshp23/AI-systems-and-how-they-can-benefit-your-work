# Everyday AI Concepts
- how can companies get value from the big data?

## Deep Learning Fundamentals
- **Deep learning** is a machine learning technique using artificial neural networks with multiple layers
- Initially used primarily for classification tasks
- Notable applications:
  - AlphaGo (Google, 2017) - mastered the complex game of Go
  - Self-driving cars
  - Traffic management systems
  - Customer classification based on spending patterns
  - Inventory control systems with predictive capabilities

## How Neural Networks Learn
- Intelligence is largely defined by the ability to learn from mistakes
- **Backpropagation** is the key learning mechanism:
  - Calculates error contribution from each neuron by propagating it backward
  - Adjusts connection weights to minimize errors
  - Essentially refines the network's internal "recipe" through trial and error

## Data Models and Classification
- A **data model** is an abstraction that helps understand larger datasets
- **Classification** involves grouping new data by comparing it with existing data

## Machine Learning Approaches
- **Reinforcement learning**: Systems create a series of rewards to guide learning
- Question: Do these powerful machines need human abilities?
- Question: Can machines learn new abilities completely autonomously?

## Evolution of Search and AI Systems
- Early 1990s: Search engines (Lycos, Infoseek, Alta Vista) required very specific prompts
- Modern approach:
  - Systems gather extensive data
  - Create online profile views to better understand user preferences

## Prompt Engineering
- To maximize current AI systems' potential, focus on writing specialized prompts
- **Prompt engineering**: Giving systems context to produce better results
  
### Prompt Engineering Techniques
1. **Creating a persona**:
   - Instead of: "What's the difference between a Surface tablet and an iPad?"
   - Try: "Imagine you're a creative professional who primarily uses illustration software. What are the benefits of a Surface tablet over an iPad?"

2. **Chain of thought prompting**:
   - Break one task into smaller sequential tasks
   - Example process:
     - Start with: "Let's think about this step by step. Imagine you're a creative professional wanting to work remotely. What are some of the best options?"
     - When the system lists options, continue building on previous responses
     - Conclude by asking for a summarized table of findings

## Challenges and Considerations
- AI reliability issues: In 2024, Google's AI system incorrectly recommended eating rocks for better health
- Legal and ethical considerations:
  - Fair use and copyright concerns
  - Use AI outputs as inspiration rather than copying and selling
- **Algorithmic traceability**: Ensuring each AI decision can be understood by humans
- **The alignment problem**: Ensuring AI systems share the same goals, context, and expectations as humans
